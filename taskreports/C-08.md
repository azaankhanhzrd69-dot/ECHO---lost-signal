## Public API Contract

### HideRules (pure C#)
```csharp
HideOutcome HideRules.Evaluate(HideKind kind, bool isIntro, int safeHidesSoFar, int safeHidesBeforeDeath)
```

### HideController (MonoBehaviour, singleton)
```csharp
static HideController Instance { get; }
bool      IsHiding    { get; }
HideSpot  CurrentSpot { get; }
void      BeginHide(HideSpot spot)  // called by HideSpot.Interact()
void      AbortHide()               // called on disable / scene unload / F1 jump

// UnityEvents (wire in Inspector)
UnityEvent<bool> OnHideBegin    // bool = forceFail; wire to I-04 HideMinigame
UnityEvent       OnBang         // wire to audio
UnityEvent       OnHideDeath    // wire to C-09
UnityEvent       OnHideSurvived // wire to audio/UI
```

### HideSpot (MonoBehaviour, IInteractable)
```csharp
HideKind  kind           // set in Inspector
Transform monsterPoint   // set in Inspector
UnityEvent OnEnter       // wire World: locker door close, camera pose
UnityEvent OnExit        // wire World: locker door open, camera restore
```

### Interact contract (I-04 must match)
```csharp
// I-04 receives forceFail via OnHideBegin(bool forceFail)
// I-04 ends the hide via: EchoEvents.EndHide(bool survived)
// HideController listens to EchoEvents.HideFinished internally
```

### C-09 (respawn) must
- Store `Progress.Snapshot()` before or at the start of each hide
- After respawn: restore snapshot (undoes any SafeHides increment), call `monster.ExitScripted()`, call `monster.ResetToDormant()`

## SafeHides rules
- `Progress.SafeHides` increments **only** on `HideFinished(true)` AND `!isIntro`
- Never increments on death
- C-09 must restore from a snapshot to undo any increment if the player dies in a later beat
