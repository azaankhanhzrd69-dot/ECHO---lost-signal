## Architecture & Findings
1. **Cursor & Input Lock**:
   - `EchoEvents.LockInput()` / `EchoEvents.UnlockInput()` from I-01 freezes player look, movement, and raycasting.
   - `Cursor.lockState = CursorLockMode.None; Cursor.visible = true;` enables mouse interaction with UI buttons. On close/success, cursor is relocked to `CursorLockMode.Locked`.
2. **Reaching World Lane Door without Cross-Lane Dependency**:
   - Implemented via a `[SerializeField] UnityEvent onDoorUnlocked` on `KeypadUI`. This allows the Inspector to link directly to whatever door component or animator World lane provides (e.g. `EchoBlastDoor.SetOpen(true)` or `DoorAnimator.Trigger()`) without requiring any code-level assembly reference across lanes.
   - Additionally triggers `EchoEvents.SetBeat(Beat.MedBay)` if `Progress.Current == Beat.Keypad`.
