## 1. Findings (Pre-Writing Report)

1. **Beat Transition (PowerOn -> Chase):**
   - Implemented `ChaseDirector.BeginChase()`, which pauses `tuning.powerOnToChaseDelay` seconds and calls `EchoEvents.SetBeat(Beat.Chase)`.
   - Wireable to the reactor core insertion / power switch interaction.
2. **Relentless Tracking via Noise Beacons:**
   - Emits synthetic noise beacons at the player's position every `beaconInterval` (0.8s) with `beaconLoudness` (1.0).
   - `MonsterAI` boosted with `SetChaseBoost(speedMultiplier, hearingMultiplier)` (e.g. hearing radius boosted 2.5x to 45m).
   - At 30m distance, alert added is `1.0 * (1 - 30/45) = 0.33` per pulse, ensuring continuous Chase state escalation and destination refresh.
3. **Monster Speed Calibration:**
   - Player sprint speed is `6.3 m/s` (from `EchoPlayerMotor`).
   - Monster speed is tuned as a ratio `chaseSpeedRatio = 0.90` (`5.67 m/s`), ensuring the monster is relentless but survivable if sprinting.
4. **Monster Spawn & Reset:**
   - Warps the monster's `NavMeshAgent` to `chaseStartPoint`.
   - Clears scripted states, resets to dormant, and applies the boost.
5. **Hide Prevention:**
   - `HideSpot.Prompt`: returns empty string during `Beat.Chase`.
   - `HideSpot.Interact()` and `HideController.BeginHide()`: reject hides during `Beat.Chase`.
6. **Balance Check Tool:**
   - ContextMenu `[ContextMenu("Report chase balance")]` on `ChaseDirector`:
     - Calculates NavMesh paths for player and monster to `podPoint`.
     - Logs path lengths, times, and escape margin in seconds.
     - Logs a warning if margin is below `tuning.minMarginSeconds` (2.0s).
7. **GameTuning Fields:**
   - Added:
     - `playerSprintSpeed = 6.3f`
     - `chaseSpeedRatio = 0.90f`
     - `chaseHearingMultiplier = 2.5f`
     - `beaconInterval = 0.8f`
     - `beaconLoudness = 1.0f`
     - `powerOnToChaseDelay = 2.0f`
     - `minMarginSeconds = 2.0f`
