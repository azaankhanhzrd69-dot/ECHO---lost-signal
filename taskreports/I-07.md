## 1. Findings (Pre-Writing Report)

1. **Columns of `sfx.csv` and ID Lookup:**
   - **Columns:** `id,file,trigger_beat,notes`
   - **Lookup mechanism:** Built `SfxTable` parser (pure C#) that reads rows and indexes by `id` (case-insensitive) and `trigger_beat`. `AudioManager` maintains a fast runtime lookup dictionary `Dictionary<string, AudioClip>`.
2. **Monster Footsteps without Referencing `MonsterAI`:**
   - Implemented `MonsterFootsteps` component on the monster GameObject.
   - Measures horizontal ground displacement per frame (`transform.position`).
   - Accumulates distance; triggers footstep audio every `effectiveStride` metres.
   - Adjusts pitch (0.85 to 1.15) and volume dynamically with horizontal speed.
   - 3D spatial audio: `spatialBlend = 1.0f`, logarithmic rolloff with min/max distance.
   - Stops completely when speed < 0.05 m/s or when GameObject is disabled.
   - Completely decoupled from Core's `MonsterAI` (zero cross-lane dependency).
3. **Triggering Sounds from Other Lanes via UnityEvents:**
   - Implemented `SfxPlayer` with:
     - `public void Play(string sfxId)` (2D playback)
     - `public void PlayAt(string sfxId)` (3D playback at GameObject position)
     - `public void PlayDefaultInteract()` (convenience for pickups / generic interactions)
   - World and Core systems can wire their Inspector UnityEvents (e.g. `OnDoorLocked`, `OnBang`, `OnSendSuccess`, `OnPickup`) directly to these methods.
   - Frame debounce prevents duplicate playback on the exact same frame.
4. **Ambience Zones & Beat Layering:**
   - `AmbienceZone` component attached to trigger colliders. Detects player entry and calls `AudioManager.Instance.CrossfadeAmbience(ambienceSfxId, crossfadeDuration)`.
   - Global Beat Layering subscribes to `EchoEvents.BeatChanged`:
     - `Boarding` through `Keypad`: Corridor ambience (`sfx_ambience_corridor`).
     - `MedBay` through `HideIntro`: MedBay ambience (`sfx_ambience_medbay`).
     - `Sneak` through `CoreHunt`: Reactor low hum (`sfx_ambience_reactor`).
     - `PowerOn` / `Chase`: Fast crossfade to high-tension chase layer.
     - `Airlock` / `Ending`: Corridor / ending atmosphere.
5. **AudioMixer Setup & Fallback:**
   - **Mixer Groups needed:**
     - `Master` -> Parameter `MasterVolume` (-80dB to 0dB)
     - `Ambience` -> Parameter `AmbienceVolume`
     - `Music` -> Parameter `MusicVolume`
     - `Sfx` -> Parameter `SfxVolume`
     - `Voice` -> Parameter `VoiceVolume`
   - **Fallback:** If no `AudioMixer` is assigned, `AudioManager` directly adjusts `AudioListener.volume` for master, and individual `AudioSource.volume` values without throwing errors.
6. **InteractTuning Fields:**
   - Added the following fields to `InteractTuning.cs`:
     - `monsterBaseStrideDistance = 1.4f`
     - `monsterMinStepPitch = 0.85f`
     - `monsterMaxStepPitch = 1.15f`
     - `monsterStepVolume = 1.0f`
     - `ambienceCrossfadeSeconds = 2.0f`
     - `defaultInteractSfxId = "sfx_keypad_beep"`
