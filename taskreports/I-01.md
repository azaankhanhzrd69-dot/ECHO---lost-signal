## Input Lock Flow
```
EchoEvents.HideStarted  →  HideLockController.OnHideStarted  →  EchoEvents.LockInput()
                                                                    ↓
                                          Motor Update() returns early (no movement, no camera)
                                          Interactor Update() returns early (no raycast, no E)
                                                                    ↓
EchoEvents.HideFinished(true)  →  begin polling Progress.MonsterPosition
                                                                    ↓
dist >= safeRadius  →  EchoEvents.UnlockInput()  +  SafeToLeave event
                                                                    ↓
                                 InteractPromptUI shows "Safe to leave" for 3 s
```
