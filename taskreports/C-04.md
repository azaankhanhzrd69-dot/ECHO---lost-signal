## Architecture & Findings
1. **Player Controller Construction:**
   - The player is created at runtime in `EchoGame.Build.cs` within `BuildPlayer()`.
   - Smallest one-line addition to attach `PlayerNoiseEmitter` to the player:
     ```csharp
     player.AddComponent<Echo.Core.PlayerNoiseEmitter>();
     ```
2. **Locomotion Mode Detection:**
   - Evaluated without package/input dependencies via `CharacterController`:
     - Crouch: `controller.height < 1.4f` (normal height is 1.75f, shrinks to 1.05f when crouching)
     - Run: `horizontalSpeed >= 5.0f` (walk speed is 4.25m/s, run is 6.3m/s)
     - Walk: default moving grounded state
     - Airborne or stationary: distance does not accumulate, no noise emitted
3. **Distance-Based Accumulation:**
   - Moving distance is measured from horizontal position delta while grounded. Once `accumulatedDistance >= stepDistance`, `EchoEvents.MakeNoise` is dispatched and accumulator resets.
