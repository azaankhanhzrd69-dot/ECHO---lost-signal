## 1. Findings (Pre-Writing Report)

1. **What is a Checkpoint:**
   - Represented by pure C# `ProgressSnapshot` that captures: `Current` (Beat), `CoresFound`, `SafeHides`, `HasMap`, `HasNote`, `MorseSent`.
   - Snapshot captured on every `EchoEvents.BeatChanged` (including F1 jumps) and whenever `SaveCheckpoint()` is called.
   - If `SaveCheckpoint()` is omitted from pickups or `OnHideSurvived`: when the player dies mid-beat, collected items inside that beat revert back to the beat-start snapshot, creating a desync where the item is gone from the world but uncredited in `Progress`.
2. **Player Respawn & Teleportation:**
   - The player uses a `CharacterController` component (configured in `EchoPlayerMotor`).
   - Safe teleportation requires disabling the `CharacterController`, setting `position` and `rotation`, calling `Physics.SyncTransforms()`, and re-enabling the `CharacterController`.
   - If no `CheckpointPoint` is assigned for the active beat, respawns at the last saved player position and logs a warning.
3. **Monster Reset on Respawn:**
   - Exits scripted mode via `monster.ExitScripted()` if scripted.
   - Calls `monster.ResetToDormant()`.
   - Warps to `point.monsterPoint` via `monster.Agent.Warp()`.
   - In `HideIntro`, re-raising the beat triggers `HideController.OnBeatChanged(Beat.HideIntro)`, placing the monster scripted outside the MedBay door.
4. **Re-raising the Beat & Subscribers:**
   - Calling `EchoEvents.SetBeat(Progress.Current)` notifies:
     - `MonsterAI.OnBeatChanged`: updates `_isActive` based on active beats (safe).
     - `HideController.OnBeatChanged`: positions monster at MedBay door if `HideIntro` (safe).
     - `LungeSequence`: only activates if beat is `Lunge`.
     - `AudioManager`: crossfades ambience to beat loop (safe).
     - `PlayerNoiseUI` / `ScreenManager`: resets/unpauses state cleanly.
5. **Death Debounce & Immunity:**
   - `_isDead` boolean flag ensures only one death sequence runs even if `OnPlayerCaught` and `OnHideDeath` fire in the same frame.
   - Deaths are strictly ignored during `Beat.Airlock` and `Beat.Ending`.
6. **Forced 4th Hide Survival State:**
   - Snapshot maintains `SafeHides = 3`. If the player hides in a locker again upon respawn, the 4th hide penalty fires (`ForcedDeath`). This is by design to prevent bypassing the rule.
7. **GameTuning Fields:**
   - Added:
     - `minDeathScreenSeconds = 1.0f`
     - `respawnFadeIn = 0.5f`
