## 1. Findings (Pre-Writing Report)

1. **Screen Building via Prefab Tool:**
   - Created Editor script [`ScreensUIBuilder.cs`](file:///c:/Users/dabas/Danny3187Dev/ECHO/ECHO---lost-signal/Assets/ECHO/Scripts/Interact/Editor/ScreensUIBuilder.cs) exposing menu **ECHO > Build > Screens UI**.
   - Generates and saves prefab at `Assets/ECHO/Prefabs/UI/ScreensUI.prefab` with all panels (`TitlePanel`, `PausePanel`, `CaughtPanel`, `EndingPanel`), volume sliders, graphics buttons, and serialized references pre-wired.
2. **Title Game Start:**
   - Handled in `ScreenManager.OnPlayClicked()`:
     - If `startSceneName` is populated, loads via `SceneManager.LoadSceneAsync(startSceneName)`.
     - If empty (single scene workflow), hides Title, locks cursor, shows gameplay, and fires `EchoEvents.SetBeat(Beat.Boarding)`.
3. **Input System:**
   - Uses `com.unity.inputsystem` (`1.20.1`).
   - Uses `Keyboard.current.escapeKey.wasPressedThisFrame` to toggle Pause.
4. **Pause Mechanism:**
   - **Pause:** `Time.timeScale = 0f; AudioListener.pause = true; Cursor.lockState = CursorLockMode.None; Cursor.visible = true; EchoEvents.LockInput();`
   - **Resume:** `Time.timeScale = 1f; AudioListener.pause = false; Cursor.lockState = CursorLockMode.Locked; Cursor.visible = false; EchoEvents.UnlockInput();`
   - Esc ignored on Title, Caught, and Ending screens.
   - **Safety:** Automatically unpauses in `OnDisable()`, on `OnBeatChanged()` (so F1 jumps or beat advances never freeze the game), and in static subsystem registration on domain reload.
5. **Ending Sequences & Order:**
   - Listens to `EchoEvents.BeatChanged(Beat.Ending)`.
   - **Order:** Good Ending screen is always shown first. If `Progress.MorseSent == true`, the Secret Ending screen is shown sequentially afterwards.
   - **Storyboard quote (`STORYBOARD.md` line 67):**
     > *"Once this is done, the secret sequence will trigger after the good ending."*
   - Displays exact narrative text cards from `STORYBOARD.md` lines 73–125 for both endings.
6. **Death ("Caught") Overlay:**
   - Method `public void ShowCaught()` wired to Core's `OnPlayerCaught` and `OnHideDeath`.
   - Shows caught panel with death text, unlocks cursor, unpauses time if paused, and invokes `OnCaughtShown`.
   - `OnRetryClicked()` (or Space/Enter) invokes `OnRespawnRequested` (Core's respawn handler wires here) and restores gameplay.
7. **InteractTuning Fields:**
   - Added:
     - `screenFadeDuration = 0.5f`
     - `endingGoodDuration = 8.0f`
     - `endingSecretDuration = 8.0f`
     - `defaultGraphicsMode = 1` (Balanced)
