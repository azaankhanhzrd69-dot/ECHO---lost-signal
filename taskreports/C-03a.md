## 1. Goal & Overview
Task C-03a created an Editor tool (`ECHO > Bake Station`) to run the procedural station construction logic in Edit Mode without entering Play Mode. The station geometry, materials, procedural textures, and meshes were persisted as assets and saved into a dedicated scene (`Station_Baked.unity`) so World and Lighting lanes can begin scene, lighting, and NavMesh work.

## 2. Findings from BEFORE WRITING

### 2.1 What `EchoGame` Constructs at Startup
In `EchoGame.BuildGame()`, the following elements are created:
1. **Scene environment**: Ambient light, fog, nebula skybox (`BuildNebulaSkybox`).
2. **Procedural materials & textures**: `CreateMaterials()` creates dynamic URP lit materials and procedural texture maps.
3. **Modular kit loading**: `LoadStationKit()` loads 3D Sci-Fi Kit starter kit prefabs via `Resources.Load`.
4. **Station geometry**:
   - `worldRoot = new GameObject("Station - Deck 03")`
   - `BuildStation()`: Floor grids, roof grids, perimeter walls, doorways, blast door frames.
   - `BuildModularAnnex()`: Annex corridors, blast doors, airlock bulkheads, observation windows.
   - `BuildSpaceBackdrop()`: Space stars, celestial bodies (blue planet, moon), viewport rings.
   - `BuildBlackHole()`: Event horizon sphere, procedural accretion disks (violet and aurora meshes).
   - `BuildEscapeShip()`: `StarSparrow1` escape craft instantiation and transform staging.
   - `BuildDecor()`: Signs with procedural quad meshes, kit crates.
5. **Interactables & Props**:
   - `AddInteractable(...)` calls for Cores, Breaker Puzzle, Notes, Airlock Exit, Relays, Logs, Supply Cases, Comms Array, Reactor Wire leads.
   - Reactor socket bases, power cell indicator meshes, carrier emitters.
6. **Corridor & Room Lights**: Point lights and spot lights added via `AddCorridorLight` and `AddLight`.
7. **Runtime Entities**:
   - Player (`BuildPlayer`): Player root, `CharacterController`, `EchoPlayerMotor`, `Camera` (tagged `MainCamera`), `AudioListener`, flashlight spotlight.
   - Monster (`BuildCreature`): Monster model (`MonsterMutant7_Skin1`), `EchoCreature`, animation graph / mixer, audio sources.
   - Audio (`LoadStationAudio`, `BuildAudio`): Ambience source, voice alert source, sound effects.

### 2.2 Edit-Mode Hazards & Fixes Applied in `StationBaker.cs`
- **MonoBehaviour Execution**: Instantiating `EchoGame` directly would invoke runtime logic in `Awake()`. **Fix**: Added `EchoGame` to an inactive GameObject (`tempController.SetActive(false)`), allowing methods to be invoked selectively via reflection (`BindingFlags.NonPublic | BindingFlags.Instance`).
- **Object.Destroy in Edit Mode**: Runtime code uses `Object.Destroy()`, which logs errors and fails to remove objects in Edit Mode. **Fix**: Used `Object.DestroyImmediate()` in `StationBaker` post-processing.
- **Audio Loading Crashes**: `LoadStationAudio()` fails if audio clips are not present in Edit Mode paths. **Fix**: Skipped `LoadStationAudio()` during bake since audio is runtime-only.
- **Procedural Asset Persistence**: Unity scene files cannot embed procedural runtime materials or meshes without them becoming missing (pink / invisible) upon reload. **Fix**: Persisted generated meshes as `.asset` files and materials as `.mat` files in `Assets/ECHO/Generated/`.
- **Collider Cleanup**: Procedural non-solid objects (stars, black hole horizon, decorative leads, seam blocks) had default primitive colliders. **Fix**: Stripped non-solid colliders using `DestroyImmediate` via `CleanUpNonSolidColliders()`.
- **Renderers Disabled by Pulse Reveal**: `EchoPulseReveal.Prepare()` disables renderers for the deprecated sonar ping mechanic. **Fix**: All renderers under `worldRoot` were explicitly re-enabled (`renderer.enabled = true`) prior to saving the scene.

## 4. What Could Not Be Serialized

When saving `Station_Baked.unity`, the following states/data cannot be serialized into the scene asset:

1. **`EchoInteractable` Auto-Properties**:
   - `EchoInteractable` uses C# auto-properties without explicit backing serialization:
     ```csharp
     public string Kind { get; private set; }
     public string Label { get; private set; }
     public int Index { get; private set; }
     ```
   - Unity does not serialize auto-properties. On scene save/reload, `Kind` becomes `null`, `Label` becomes `null`, and `Index` becomes `0`.
   - **Recovery**: At runtime startup (or in C-03c), either re-populate these fields by inspecting the GameObject name (e.g., target names match `Kind` and `Label`), or convert `EchoInteractable` properties to `[SerializeField]` private backing fields.

2. **`EchoGame` Field Collections**:
   - `EchoGame` is not saved in `Station_Baked.unity` (the temporary controller was destroyed). Consequently, the following lists and references on `EchoGame` are empty/null upon loading:
     - `interactables` (`List<EchoInteractable>`)
     - `corridorLights` (`List<Light>`)
     - `annexBulkhead` (`GameObject`)
     - `airlockBulkhead` (`GameObject`)
     - `escapeShip` (`GameObject`)
     - `blackHole` (`GameObject`)
     - `relayIndicators` (`GameObject[3]`)
     - `reactorWires` (`LineRenderer[3]`)
     - `reactorCellIndicators` (`GameObject[3]`)
     - `reactorSocketIndicators` (`GameObject[3]`)
     - `reactorWireConnectors` (`GameObject[3]`)
     - `pulseRevealTargets` (`List<EchoPulseReveal>`) — *Note: Dropped feature; pulse reveal is no longer needed.*
   - **Recovery in C-03c**: These references must be re-collected once during startup via `FindObjectsByType` / `GameObject.Find` when `useBakedStation` is enabled.
