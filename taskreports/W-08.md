## Findings

1. **InputLocked** — already in `EchoEvents`; no addition needed.
2. **PlayLine(id)** — NOT in `EchoEvents`. Each `PlayLine` step fires a `UnityEvent onStepEvent`; wire to `DialoguePlayer.PlayById(id)` in the Inspector.
3. **Camera** — player camera built at runtime, tagged `MainCamera`. Director resolves it via `Camera.main` at `Play()` time (no EchoGame edit needed). Cutscene camera has **no** `AudioListener` — player camera's listener stays enabled, zero clash.
4. **Interrupt** — `RestoreAll()` called on `Stop()`, `OnDisable()`, `OnDestroy()`, and on any external beat change (F1 jump).

---

## Design Notes

- `CutsceneDirector.Play()` is **ignored with one warning** if already playing (no restart).
- `allowSkip` defaults **false** on `CutsceneSequence`; skip requires holding the key for `skipHoldDuration` seconds.
- `RestoreAll()` is idempotent: safe to call multiple times.
- `EchoEvents.BeatChanged` subscription breaks a running cutscene if the beat changes externally mid-play.
- No Timeline. No magic numbers. No `Find*` in Update.
- Namespace: `Echo.World`. Cross-lane via `EchoEvents`, `Progress` only.
