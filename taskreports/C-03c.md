## 1. Goal
Add a serialized `useBakedStation` flag to `EchoGame`.
- **When OFF (false, default)**: Station is procedurally generated at runtime and scene cameras/lights are disabled on load, keeping behavior byte-for-byte identical to before.
- **When ON (true)**: Station procedural generation is skipped, scene cameras and lights remain intact, references are re-collected from the pre-baked scene, and runtime entities (player, creature, audio, UI) spawn normally.

---

## 2. Re-collected References (Point 4)

When `useBakedStation` is true, `CollectBakedStationReferences()` runs once at startup:
1. `worldRoot`: Retrieved via `GameObject.Find("Station - Deck 03")`.
2. `annexBulkhead` & `airlockBulkhead`: Found via `GameObject.Find("Power-controlled annex blast door")` and `GameObject.Find("Power-controlled airlock blast door")`.
3. `escapeShip`: Found via `GameObject.Find("StarSparrow - escape craft")`; initial local position, rotation, and scale are cached.
4. `blackHole`: Found via `GameObject.Find("Event horizon / escape destination")`.
5. `corridorLights`: Found via `FindObjectsByType<Light>()` filtering for lights under `worldRoot`.
6. `interactables`: Re-collected via `FindObjectsByType<EchoInteractable>()`. Since Unity does not serialize auto-properties, their `Kind`, `Index`, and `Label` are restored based on their GameObject names and positions. Cores are sorted to indices 0, 1, 2 to preserve game logic ordering.
7. `relayIndicators`: Re-collected from `"Relay carrier emitter"` transforms under the relay interactables.
8. `reactorWires` & `reactorWireConnectors`: Re-collected from `LineRenderer` components and `"Reactor lead connector ..."` transforms under wire interactables.
9. `reactorSocketIndicators` & `reactorCellIndicators`: Re-collected from `"Reactor cell receptacle ..."` and `"Reactor cell socket ..."`.
10. Camera / AudioListener clash check: If an existing camera has an active `AudioListener`, it is disabled so it does not conflict with `BuildPlayer()`.

Logs a single line:
`[EchoGame] Using baked station. Found {doors} doors, {pickups} pickups, and {lights} lights.`
